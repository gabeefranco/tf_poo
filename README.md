# TF_POO
Projeto criado automaticamente com:

- Java 25
- Spring Boot 4.1.0
- Vaadin 25.2.1
- Maven

## Executar em modo de desenvolvimento

```bash
mvn spring-boot:run
```

Depois acesse:

```text
http://localhost:8080
```
